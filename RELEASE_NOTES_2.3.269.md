# VPN Panel 2.3.269

- Telegram groups are shared workspaces: every member of a linked group can use the bot.
- Group members do not need a panel account, Telegram numeric-ID binding, or Telegram administrator status.
- The panel admin who owns the group also does not need to be a Telegram group administrator.
- A one-time code issued from the authenticated panel session is sufficient to link a group.
- Every command and inline callback still executes under the live permissions, user ownership, server targets, protocol access, quotas, expiry and active status of the group owner admin.
- Private bot chats keep their existing direct Telegram-to-panel account binding for safety.
